## 🔍 CSP Implementation Overview

### Core CSP Directives

The CSP is generated by [getFrameContentSecurityPolicyDirectives()](apps/chat/src/utils/server/headers-helpers.ts) function and includes:

```
object-src 'none';
base-uri 'self';
script-src 'self' [ORIGINS] [SOURCES] https://cdn.jsdelivr.net/npm/monaco-editor@0.54.0/ 'nonce-{UUID}' ['unsafe-eval' in dev];
worker-src 'self' blob:;
frame-ancestors [frame-ancestors-directive];
frame-src [frame-src-directive];
```

### Directive Breakdown

| Directive | Value | Purpose |
|-----------|-------|---------|
| **object-src** | `'none'` | Prevents plugin/object execution |
| **base-uri** | `'self'` | Restricts base URL sources |
| **script-src** | See details below | Controls script execution sources |
| **worker-src** | `'self' blob:` | Allows self and blob workers |
| **frame-ancestors** | Configurable | Controls who can embed this app in iframe |
| **frame-src** | Configurable | Specifies iframe content sources |

---

## 🔐 Script Source Configuration

The `script-src` directive includes:

1. **`'self'`** - Scripts from same origin
2. **Dynamic iframe origins** - From `ALLOWED_IFRAME_ORIGINS` env var (via `insertSelf()`)
3. **Dynamic iframe sources** - From `ALLOWED_IFRAME_SOURCES` env var (via `insertSelf()`)
4. **Monaco Editor CDN** - `https://cdn.jsdelivr.net/npm/monaco-editor@0.54.0/`
5. **Nonce** - `'nonce-{BASE64_ENCODED_UUID}'` for inline scripts
6. **Development Only** - `'unsafe-eval'` added when `NODE_ENV === 'development'`

### Default Script Sources

When no environment variables are configured:
```
script-src 'self' [empty] https://cdn.jsdelivr.net/npm/monaco-editor@0.54.0/ 'nonce-{nonce}'
```

### Custom Script Sources

Environment variable `ALLOWED_SCRIPT_SOURCES` allows override:
```
ALLOWED_SCRIPT_SOURCES='self' https://trusted-cdn.com
```

**Default:**
```
'self' ALLOWED_IFRAME_ORIGINS ALLOWED_IFRAME_SOURCES
```

## 📍 Implementation Locations

### 1. Middleware Level - [proxy.ts](apps/chat/src/proxy.ts)

**File:** [apps/chat/src/proxy.ts](apps/chat/src/proxy.ts)  
**Type:** Next.js Edge Middleware  
**Applies To:** All routes except API, `_next/static`, `_next/image`, `favicon.ico`

```typescript
// Applied to request headers and response
requestHeaders.set(HeadersNames.CONTENT_SECURITY_POLICY, contentSecurityPolicyHeaderValue);
response.headers.set(HeadersNames.CONTENT_SECURITY_POLICY, contentSecurityPolicyHeaderValue);

// X-Frame-Options header for non-iframe deployments
if (!process.env.ALLOWED_IFRAME_ORIGINS && !process.env.ALLOWED_IFRAME_SOURCES) {
    response.headers.set('X-Frame-Options', 'SAMEORIGIN');
}
```

**Key Features:**
- Generates nonce per request
- Special handling for signin pages (can disable frame options if configured)
- Sets `X-Frame-Options: SAMEORIGIN` as fallback when iframe not enabled

## 🔧 Environment Variables Configuration

### Key CSP-Related Environment Variables

| Variable | Type | Default | Description |
|----------|------|---------|-------------|
| `ALLOWED_IFRAME_ORIGINS` | String | `none` | URLs allowed to embed chat via `frame-ancestors` |
| `ALLOWED_IFRAME_SOURCES` | String | `none` | iframe content sources allowed via `frame-src` |
| `ALLOWED_SCRIPT_SOURCES` | String | `'self' ALLOWED_IFRAME_ORIGINS ALLOWED_IFRAME_SOURCES` | Custom `script-src` directive |
| `IS_IFRAME` | Boolean | `false` | Enables iframe overlay mode |
| `ALLOW_OPEN_SIGNIN_PAGE_IN_IFRAME` | Boolean | `false` | Permits signin page in iframe |

### Frame Ancestors Directive Logic

```typescript
if (frameAncestors && !disabled) {
    ancestorsDirective = 'self' + frameAncestors;  // 'self' prepended
} else {
    ancestorsDirective = "'none'";  // Prevent all embedding
}
```

**Effect:**
- Default (`ALLOWED_IFRAME_ORIGINS` not set): `frame-ancestors 'none'` → Cannot embed in iframe
- When set: `frame-ancestors 'self' {origins}` → Can embed in specified origins
- Disabled (signin pages): `frame-ancestors 'none'` → Restricted

### Frame Source Directive Logic

```typescript
if (frameSrc && !disabled) {
    frameSrcDirective = 'self' + frameSrc;  // 'self' prepended
} else {
    frameSrcDirective = "'none'";  // No iframe content allowed
}
```

**Effect:**
- Default: `frame-src 'none'` → No iframe content allowed
- When set: `frame-src 'self' {sources}` → iframe content from specified sources allowed

## 🎯 CSP Implementation Quality Checks

### ✅ Strengths

1. **Nonce-Based CSP** - Uses cryptographically secure UUIDs for inline scripts
   - Format: `Buffer.from(crypto.randomUUID()).toString('base64')`
   - Prevents script injection attacks

2. **Multiple Application Points**
   - Middleware level (Edge runtime)
   - Page level (Server-side)
   - Fallback logic ensures CSP is always applied

3. **Environment-Driven Configuration**
   - Supports different deployment scenarios
   - iframe embedding is opt-in
   - Default is restrictive (`'none'` for frame-ancestors/frame-src)

4. **Development Exception**
   - Adds `'unsafe-eval'` only in development
   - Production builds don't include it

5. **Security Headers Complement**
   - Sets `X-Frame-Options: SAMEORIGIN` when iframe not configured
   - Sets `X-Content-Type-Options: nosniff`
   - Provides defense in depth

6. **Header Cleaning**
   - Removes excess whitespace
   - Prevents malformed CSP headers

7. **Duplicate Prevention**
   - Helper function `insertSelf()` prevents duplicate `'self'` entries
   - `replaceAll("'self'", '')` removes existing values before adding

### ⚠️ Areas to Monitor

1. **Monaco Editor CDN Hard-Coded**
   - Always allows `https://cdn.jsdelivr.net/npm/monaco-editor@0.54.0/`
   - Consider making this configurable with fallback validation
   - Current version: 0.54.0 (verify for security updates)

2. **Unsafe-Eval in Development**
   - Necessary for development debugging
   - Ensure dev files aren't accidentally deployed

3. **Frame-Ancestors Default is Restrictive**
   - Requires explicit configuration for overlay/iframe mode
   - Ensures security by default (good!)
   - Requires documentation awareness (monitor for support issues)

4. **ALLOWED_SCRIPT_SOURCES Precedence**
   - When set, it completely replaces the default
   - Users must include `'self'` if needed
   - Documentation shows default includes iframe origins, but consider improving clarity
